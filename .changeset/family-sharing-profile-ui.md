Family sharing, Profile UI (#617, tranche 2): the Profile page (web and native) gains a Family sharing section — designate another Eciperay user by account email, see current designations, and remove one with confirmation (removal ends that person's automatic access immediately). The client account API gains list/create/delete family-sharing calls against the tranche-1 endpoints. Recipes shared via a family designation now carry a "Family" badge in Shared With Me / the unified Recipes browse instead of the generic "Shared" badge.
